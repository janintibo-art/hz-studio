# Contexte projet
Nom : HZ Studio. Dépôt envisagé : janintibo-art/hz-studio. Dossier local : ~/hz_studio.
Objectif : Android APK + Windows EXE depuis GitHub Actions, livraison ZIP dans Download, Termux sans PC local.
V1 : générateur de fréquence sélectionnable, préréglages, Schumann 7,83 Hz modulé sur une porteuse audible.
Étapes futures : lecteur de musique et conversion de hauteur sans toucher au tempo, puis éventuellement routage Windows et capture Android dans les limites de l'OS.
Règles de livraison : un ZIP unique hz_studio_vN.zip à racine hz_studio/, fichiers modifiés uniquement pour les mises à jour, commandes Termux unitaires.
